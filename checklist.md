# Tuning checklist (after two weeks)
1. Collect every correction you made to the agent twice. Turn each into one rule.
2. Delete rules the agent already follows without being told.
3. Keep the file under 100 lines. Move long docs to docs/ and link them.
4. Put exact commands, not descriptions.
5. Add a "Do not" list from real mistakes.
6. Re-read after each major dependency change.
