# CLAUDE.md / AGENTS.md templates

Context files for AI coding agents (Claude Code, OpenAI Codex, Cursor, Copilot agents). Each file is short on purpose: agents follow a few concrete rules much better than long prose.

## Free in this repo
- [`universal-rules.md`](universal-rules.md): rules that belong in every project.
- [`nextjs-typescript.md`](nextjs-typescript.md): a complete example for a Next.js + TypeScript app.
- [`checklist.md`](checklist.md): how to tune your file after two weeks of real use.

## How to use
1. Copy a template to your repo root as `CLAUDE.md` (Claude Code) and/or `AGENTS.md` (Codex, Cursor and others).
2. Replace every `[bracketed]` item with your project's real commands and paths.
3. Delete any rule you do not need. Shorter is better.
